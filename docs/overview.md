# Overview

**One per cloud** (rendered by the chart):

| resource | Keystone object |
|---|---|
| `IdentityDomain` `keycloak` | the domain federated users, their groups and their projects live in, apart from Default's admin and service users |
| `IdentityFederationProvider` `keycloak` | the Keycloak realm as an identity provider: `remote_ids` = the realm's issuer, shadow users in the `keycloak` domain (given by name) |
| `IdentityMapping` `keycloak_mapping` | a user in the Keycloak `tenants` group becomes the Keystone user `sub`, named after their username, and a member of the group `tenant-<username>-members`; anyone else matches no rule and is refused |
| `IdentityFederationProtocol` `openid` | binds the provider to the mapping |

**One per tenant user** (generated by the chart's Kyverno `GeneratingPolicy`): in the Krateo platform a
tenant is a user, and their first sign-in creates their tenant Namespace, labelled
`krateo.io/tenant=true` and `krateo.io/tenant-user=<username>`. That Namespace is the trigger (Kyverno
reads Namespaces with its default role, so the chart needs no access to Secrets). The policy generates:

| resource | Keystone object |
|---|---|
| `IdentityProject` `tenant-<username>` | the user's project, in the `keycloak` domain |
| `IdentityGroup` `tenant-<username>-members` | the group the mapping puts the user in |
| `IdentityGroupRoleAssignment` | `member` on the project, for the group |

The policy synchronizes: deleting the tenant Namespace (deprovisioning) deletes the three resources,
and their deletion policy (`tenants.deletionPolicy`, default `delete`) removes the Keystone objects.
Users whose tenant Namespace exists before the chart is installed are covered too (`generateExisting`).
A Namespace without a valid `krateo.io/tenant-user` (lowercase letters, digits and dashes) is ignored.

The one-per-cloud resources default to `orphan`: uninstalling or pruning the chart never cuts every
federated user off. Platform administrators get no OpenStack rights from this chart; like every user,
they get their own tenant project.
